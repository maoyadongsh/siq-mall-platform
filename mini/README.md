# SIQ 优选商城原生小程序

这是独立原生微信小程序源码，不包含 Vue DOM，也不把浏览器模拟称为小程序验收。商城账号登录、刷新、退出与共用业务 API 已适配；微信平台登录、微信地址、订阅发送、体验版和真机结果未核验。

## 本地配置

1. 使用微信开发者工具导入本目录。`project.config.json` 的 `appid` 刻意留空，只在本机私有配置中填写真实 AppID，不提交密钥。
2. 在 `app.js` 将 `apiBaseUrl` 改为隔离后端地址。真机必须使用已备案且配置到微信后台的 HTTPS 请求/媒体域名，不能使用 `127.0.0.1`。
3. 后端运行 `auth/mini/login/`、`auth/mini/refresh/`、`auth/mini/logout/` 及既有业务路由。商城账号会话与浏览器 Cookie 会话独立，refresh 存于小程序本地存储。
4. 运行 `npm test`。该命令只执行 Node 平台适配测试，不代表微信开发者工具编译、体验版或真机通过。

官方登录文档已核对：临时 code 仅一次使用，服务端需通过 `auth.code2Session` 换身份，`session_key` 不能下发。当前没有 AppID、AppSecret、平台账号、模板、域名或真机，故没有实现或声称 `wx.login` 换商城会话。地址与订阅页面抓取本次返回 404，继续标记未核验。登录页的微信登录和微信地址按钮仅提示未配置，不伪造调用结果。
