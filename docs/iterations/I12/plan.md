## 1. 目标

在不改变业务 API、交易算法和权限规则的前提下，对现有 PC 商城与移动 H5 做一次可复验的体验收口：按真实浏览器检查响应式布局、键盘焦点、触控目标、减少动态效果和关键交易路径，修复实际发现的问题，并留下可追溯的自动验证与人工验收证据。

## 2. 本轮范围

1. 首页、商品列表、商品详情、购物车、结算、订单和运营代表页的 PC/H5 走查。
2. 视口 320、375、390、430、768、1440px 的横向溢出、导航切换、底部操作区和内容遮挡检查。
3. 键盘 Tab 顺序、可见焦点、表单标签、按钮可访问名称、图片替代文本及减少动态效果检查。
4. 触控目标、安全区和加载/空/失败/禁用/成功状态抽查。
5. 仅修复走查确认的问题；没有缺陷的方向不制造改动。
6. 更新迭代计划、handoff、验收台账和证据索引。

## 3. 不在本轮范围

- 不新增或修改后端业务接口、OpenAPI、数据库迁移和交易金额算法。
- 不改变报价、库存、优惠券、订单找回、模拟支付、幂等、履约和权限语义。
- 不声称完成微信开发者工具、体验版、iOS/Android 真机或微信内 H5 验收。
- 不声称完成 Ubuntu 24.04 原生预发、规定负载性能或项目整体上线验收。
- I12 未闭环前不启动 I13。
